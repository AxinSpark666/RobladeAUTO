  Roblade 自动农场工具 — 使用说明（Windows）
  版本：1.0.1（见 exe 文件名中的版本号）
════════════════════════════════════════════════

本说明只描述 exe 的使用方法。exe 为单文件程序，无需安装任何环境。


一、环境要求
──────────────────────────────
1. Windows 10/11 64 位，不需要安装 Node.js 或任何依赖
2. 能访问游戏服务器 roblade.com。
   国内网络不通时：在 exe 同目录创建一个 .env 文件，内容写
   PROXY=http://127.0.0.1:7897 （换成你自己的代理地址）
3. 本机 3000 端口空闲（被其他程序占用时会自动顺延到 3001~3009）
4. 任意现代浏览器即可（Windows 自带 Edge），启动后浏览器会自动打开操作界面


二、首次使用流程
──────────────────────────────
1. 双击 exe 启动，浏览器自动打开操作界面，同时出现一个终端窗口（可最小化）
2. 激活：页面显示本机"机器 ID"，把机器 ID 发给作者，获取当前 2FA 校验码
   （约 11 分钟内有效），输入后完成激活
3. 设置主密码：用于加密保存你的钱包私钥，忘记无法恢复，务必牢记
4. 点「批量导入」粘贴钱包私钥（每行一个，或从 .txt 文件导入）
5. 点「登录」即可开始使用；之后每次启动只需输入主密码解锁


三、日常使用
──────────────────────────────
· 账号管理：登录、状态刷新、排序、删除账号
· 自动农场：勾选账号并保存托管设置，后台每 30 秒自动监控农场状态
  （农作物/养殖成熟倒计时、仓库占用情况）
· 自动收获 / 自动种植 / 自动喂养：在农场卡片上开启对应开关自动执行，
  或点「收获全部」「立即补种」「立即喂养」按钮手动执行


四、停止服务
──────────────────────────────
· 直接关闭终端窗口，或按 Ctrl+C
· 已运行时重复双击 exe 不会重复启动，只会打开已有页面（单实例保护）
· 停止后页面顶部会出现红色警示条「服务已停止」，属正常现象，关闭页面即可


五、免责声明（请务必阅读）
──────────────────────────────
1. 私钥安全：本工具只在本地加密保存你的钱包私钥（主密码 + AES-256-GCM 加密，
   存储于用户目录 ~/.roblade-automation/ ），**不会上传、收集或盗取任何私钥**。
2. 程序仅监听本机 127.0.0.1 端口，不对外提供任何网络服务；所有游戏操作
   均以你本人的身份直连游戏官方服务器。
3. 请妥善保管主密码与账号库文件（accounts.json），切勿将账号库文件发送给任何人。
4. 本工具是游戏自动化程序，使用存在违反游戏条款/账号封禁的风险，

六、常见问题
──────────────────────────────
· Windows 提示「已保护你的电脑」：exe 未购买代码签名证书，属正常提示，
  点「更多信息 → 仍要运行」即可
· 页面打不开 / 刷新报错：说明服务已停止（终端窗口已关闭），重新双击 exe 启动
· 换电脑使用：需重新激活并重新导入私钥，账号库不随 exe 迁移
· 杀毒软件误报：pkg 打包的程序偶尔被误报，可加入信任
